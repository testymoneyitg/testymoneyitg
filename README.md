# Testy Money ITG — Website v2

A clean, page-by-page static artist website for GitHub Pages.

Pages: Home, Music, News, About, Media, Press, Contact.

This version uses the two supplied artist photographs locally. Selected music artwork and press preview images are loaded from public artist/publication image URLs so the site can show the artwork without requiring a CMS, API key, database, or login.

## GitHub Pages
Upload the contents of this folder to the root of `testymoneyitg.github.io`. Do not upload the ZIP itself. In Settings → Pages, choose Deploy from a branch, then `main` and `/ (root)`.
